# Create a leaflet map from eBird observations

Create a leaflet map from eBird observations

## Usage

``` r
bird_map(ebird_file)
```

## Arguments

- ebird_file:

  Path to a MyEBirdData CSV file.

## Value

A leaflet map.

## Examples

``` r
if (FALSE) { # \dontrun{
bird_map("data/MyEBirdData.csv")
} # }
```
